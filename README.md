# 👗 Atelier AI — Virtual Try-On

Trang web thử trang phục bằng AI, chạy hoàn toàn trên trình duyệt.  
Powered by **Google Gemini 2.0 Flash** · Hosted on **GitHub Pages**

## Cách dùng

1. Mở trang web (link GitHub Pages của bạn)
2. Nhập **Gemini API Key** vào góc trên bên phải → bấm **Lưu**
3. Upload ảnh **người mẫu** và ảnh **trang phục**
4. Chọn phong cách → bấm **Tạo ảnh ghép**

## Lấy Gemini API Key miễn phí

Vào [aistudio.google.com](https://aistudio.google.com) → **Get API Key** → **Create API key**
